# Проверка проекта

Локальная проверка: 24 сентября 2026 года. Node.js 24.11.1, Python 3.10,
MySQL 8.4.11 в Docker, Chromium через Playwright 1.58.2.

| Этап | Проверка | Результат |
|---|---|---|
| ЛР №1 | `npm run check:lab1` в `labs/lr1/frontend` | Сборка и 20 тестов прошли |
| ЛР №2 | `pytest -m 'not integration' -q` из backend | 32 теста прошли |
| ЛР №3 | `backend/.venv/bin/python tools/test_backend.py` | Все 46 тестов прошли, без пропусков |
| ЛР №4 | `npm run build`, `npm test` из frontend | Сборка и 10 тестов прошли |
| ЛР №4 | `npm test` из e2e, работающие Angular/Flask/MySQL | Все 3 сценария прошли |

Серверные проверки включают CRUD, постоянство данных между экземплярами Flask,
совместную фильтрацию по статусу и поиску, буквальные `%`/`_`, защиту от SQL-инъекции,
проверку связей, каскадное удаление истории и откат создания/изменения при сбое события.

Браузерные сценарии проверяют создание, обновление страницы, редактирование статуса,
историю, подтверждение удаления, поиск, пустой результат, сетевой сбой и повторную
загрузку, валидацию формы и неизвестный маршрут. После тестов их заявки удалены.

Дополнительные тесты: произвольные ID, повторное применение фильтра и поиск в ЛР №1;
совместный фильтр и неизменность данных при неправильном оборудовании в backend;
сохранение карточки и доступность повторной попытки при ошибке DELETE в frontend.

Интерфейс визуально проверен при ширине 1440 и 390 пикселей: русский текст отображается
корректно, на мобильном экране отсутствует горизонтальное переполнение страницы.
В SQL загрузки данных явно установлена UTF-8, чтобы Docker init не искажал кириллицу.

GitHub Actions настроен на оба интерфейса и backend с MySQL 8.4; удалённый запуск CI
в рамках этой работы не выполнялся. Отладочные упражнения с ручной установкой
breakpoint и личные ответы на контрольные вопросы остаются материалом для защиты.

Чистая установка через Docker Compose отдельно проверена на новой временной базе:
схема, UTF-8 seed и права SELECT/INSERT/UPDATE/DELETE созданы автоматически.
Временная база после проверки удалена; рабочая база сохранена.
