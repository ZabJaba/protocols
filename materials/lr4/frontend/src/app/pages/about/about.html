О ПРОЕКТЕ

Сервис заявок ИТ-отдела

Эталонный проект дисциплины «Протоколы и интерфейсы информационных систем».

Задача системы

Сотрудники учебного центра регистрируют неисправности, а ИТ-специалисты сопровождают обращения до решения. Заявки связаны с оборудованием; изменения отражаются в истории.

Как проходит запрос

Angular принимает действие пользователя и отправляет HTTP-запрос с JSON. Flask проверяет данные, выполняет операцию и обращается к MySQL параметризованным SQL-запросом. Ответ сервера обновляет интерфейс.

Четыре этапа разработки

  1. Интерфейс и состояние Angular.
  2. HTTP API и валидация на Flask.
  3. Связанные данные и транзакции MySQL.
  4. Интеграция, формы, отладка и сквозные тесты.

Границы учебной версии

Сервис предназначен для локальной учебной среды. Учётные записи и права доступа не реализованы. Справочник оборудования подготовлен SQL-сценарием; управление заявками доступно через интерфейс.
